---
name: Desktop text personalization
description: Theme ownership for editable desktop display copy and its colors.
---

Desktop text personalization keeps the three text values shared across themes, while each element has an independent light-theme and dark-theme color. Automatic contrast may temporarily override those colors for any wallpaper type without replacing the saved choices.

**Why:** Background images and solid backgrounds can have very different values in light and dark themes, so one text color cannot guarantee readable or intentional contrast in both.

**How to apply:** Persist shared copy, per-theme colors, and the automatic-contrast preference. Sample picture regions per text element; evaluate solid colors directly. Disabling automatic contrast must restore the saved theme colors.
